# First-time path audit

A reader needs only this complete folder and a browser to read it. No viewer
server, build, account or download is part of opening the companion.

| Need | In-folder route |
| --- | --- |
| Corporate approval, script policy and safe clone | Start safely / Phase 0 |
| Short setup path with matching detailed anchors | Quick setup / Phases 1-3 |
| Installed-first module list and retained installed versions | Phase 2 |
| Timeouts, partial vendor/reboot state and source/profile acceptance | Phases 1-3 / Recover |
| Explicit human package acquisition vs daily no-restore checks | Quick development / Phase 4 |
| Exact human sample requests, F5 and existing-image boundaries | Phase 5 |
| GitHub review, actual commands/results and CI scope | Phase 6 |
| Optional existing AKS/ACR, real inputs and fail-closed approval | Quick delivery / Phase 7 |
| Short rehearsed coding demo and safe schedule fallback | Quick presentation / Present |
| Exact command/prompt text, declared once | Command and prompt libraries |
| Dated observations vs laptop/live-action evidence gaps | Evidence register |
| Manual progress, search, shortcuts, theme, printing and storage denial | Welcome / Keys |

Static gates check every quick step's detailed target/anchor and source-bound
code hashes. No screenshots or machine observations are fabricated. A
successful static audit is not a visual rehearsal or laptop acceptance.
