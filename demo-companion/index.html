    Windows 11 workstation journey

    A guided, offline companion for installed-first setup and a synthetic developer demo. Read the quick path, open its detailed activity, and keep human approval separate from machine evidence.

    Start the setup journey →Already verified? Develop →

    What this companion does and never does

    This folder is the viewer. Open index.html directly from disk. No server, build, account, CDN, remote font or network API is needed to read the companion.

    !
    Instructions are not execution or machine verification

    Buttons copy text, navigate, change this guide's theme or record manual progress. They never execute shells, download tools, elevate, change policy/PATH/profile, install, restore packages, authenticate, launch services or contact Azure.

    Start with prerequisites and safe source review. If the laptop is already accepted, skip installations and use the developer path. A stopped partial Microsoft base is not successful Finish/reboot/resume. Preserve installed tools/settings, Copilot accounts and WSL/distro data.

    The underlying repository has dated successful hosted checks. Your laptop's setup, Restore, sample requests, approved extension profile and optional AKS delivery still need real human acceptance. See the evidence register.

    Read, navigate, copy and print

    Slides
    Default at least 600px wide and 520px high; short/phone screens use a long page and drawer. ?deck=off reads the long page; ?deck=on forces slides.
    Navigate
    Previous/Next, section tabs, numbered actor-coloured circles; arrows, Home/End, M for slide list, touch swipe. Deep links such as #step-6a, #slide=3 and #slide=last.
    Search and theme
    / or Ctrl+K searches local content. ? shows keys. T changes Light/Dark; light is default, ?theme=dark is explicit. Escape closes overlays.
    Manual progress
    Tick a step or Mark page done; counters and Resume reflect self-reported progress only. Storage failures are shown; memory-only progress does not survive navigation.
    Copy
    Copies exactly the visible code. Browser clipboard API plus a file:// textarea fallback; blocked copies show a warning. Required unresolved values remain visibly unresolved.
    Privacy
    Only a reviewed main SHA may be entered for optional dispatch instructions, kept in this tab's session storage. Never enter credentials, tokens or customer data. Clear tab values is available on value panels.
    Print
    Use the browser's Print command. Local print styles expose all slide content and omit navigation controls. Online source links are user-clicked only.

    The complete folder is portable. Keep local assets, data and pages together; copying only index.html breaks it. Source/generator files are included for maintainers, but opening the viewer never runs them.

    Evidence labels are scoped, not promises

    • Proven liveA dated observed result, only for its named revision/runtime/scope. It is not laptop or deployment acceptance.
    • DocumentedGrounded in repository code/tasks/docs; the corresponding live operator journey is not claimed as rehearsed.
    • Not rehearsedNo successful live rehearsal is recorded here. Inspect prerequisites, stop conditions and expected evidence first.
    • ProposedA future design or optional assessment, not an installed or deployed capability.
