    Terms that must not be conflated

    Preflight
    Read-only prerequisites/reachability; no installation and not complete laptop acceptance.
    Installed-first module
    One human-selected inventory/confirmation; retain compatible installed state, stop unknown/incompatible before downloads.
    Verify
    Read-only required output/version checks; post-setup FAIL means not accepted; profile/source acceptance remains human.
    Restore
    Explicit human package/image acquisition, never hidden in daily checks/F5/Run.
    NOT RUN
    A command's prerequisite or allowed scope is absent; not a pass, not a prompt to install as an agent.
    Recorded evidence
    Dated exact-revision/runtime observation, not a fresh live laptop result.
    Stopped partial
    Interrupted legacy/vendor setup; not confirmed successful base, resume or rollback.
    Dispatch
    Separate human current-main deployment request; not independent environment approval or rollout acceptance.
    Cleanup
    Exact positively owned unchanged output review/removal, not source reset, cache purge or workstation uninstall.

    Offline and synthetic-data boundaries

    • Keep the complete folder. No remote assets/CDNs/webfonts, JSON fetch, network APIs or credential collection.
    • Clipboard is copy-only, with explicit unresolved-value/denial feedback. Only a non-sensitive full reviewed main SHA can fill optional dispatch instructions.
    • Values use this tab's session storage, not files/server/localStorage. Clear tab values explicitly; browser session restore may retain them.
    • Progress/theme use distinct workstation browser keys, never another companion's keys. Denial/corrupt state has visible feedback and manual memory-only fallback.
    • Expected sample values, labelled capture placeholders and old CI are never invented live screenshots/results.
    • No setup/repair/elevation/policy/authentication/Restore/real app/container/cloud action is performed by this guide.
